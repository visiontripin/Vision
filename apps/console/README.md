# Vision Server — Windows/console эксперимент

> **Внутренняя техническая заметка, не инструкция по установке.** Подтверждённого
> релиза нет. Сборка, UAC/SCM, права файлов, автозапуск и runtime на реальной Windows
> не проверены. Не скачивать, не устанавливать и не рекомендовать этот эксперимент.

## Статус

`apps/console` содержит прототип отдельной Windows-службы Vision Server. Это legacy-
контур одно-владельческого API/SQLite, а не мультипользовательский API v2 и не
локальная среда для теста платформы независимой музыки. Для проверки v2 используйте
только loopback-сценарий [`../../docs/BETA-WINDOWS-LOCAL.md`](../../docs/BETA-WINDOWS-LOCAL.md).

Android-приложение Vision Audio остаётся клиентом внешнего API: серверный Node/JNI
удалён из APK.

## Заморозка и ограничения поставки

- Workflow `.github/workflows/console.yml` запускается вручную. По умолчанию он
  показывает уведомление о заморозке; проверка требует явного `validate: true`.
- Ручная проверка создаёт диагностический артефакт, но не выпускает GitHub Release.
- Workflow не запускается на push, pull request или тег и не может публиковать релиз.
- Не использовать страницу `releases/latest` для поиска этого продукта: проверенного
  установщика там не обещано.

Ранее сформулированное требование владельца к Windows-службе остаётся открытым и
сталкивается с заморозкой desktop/console до PMF. Заморозка не означает ни выполнения,
ни отмены этого требования. Решение и критерии будущей проверки — в
[`../../docs/HOME-SERVER-WINDOWS.md`](../../docs/HOME-SERVER-WINDOWS.md) и
[`../../docs/adr/0016-platform-freeze-until-pmf.md`](../../docs/adr/0016-platform-freeze-until-pmf.md).

## Состав прототипа (не подтверждён на Windows)

В коде предусмотрены NSIS-пакет для per-machine установки, Node/API, панель Tauri,
FFmpeg, WinSW-служба `VisionServer`, первичная настройка владельца через loopback и
каталог данных в `%ProgramData%`. Это описание замысла кода, а не подтверждение, что
компоненты успешно собираются или безопасно работают в Windows.

## Условия до дальнейшей работы

До отдельного решения владельца не запускать ручной Windows workflow, не публиковать
артефакты и не открывать API в домашнюю сеть или интернет. Если эксперимент будет
разморожен, пройти все пункты проверки из
[`../../docs/HOME-SERVER-WINDOWS.md`](../../docs/HOME-SERVER-WINDOWS.md) на чистой
Windows 10/11 x64 и обновить эту заметку только после фактических результатов.
