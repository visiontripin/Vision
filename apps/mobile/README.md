# Vision Audio — мобильный legacy-клиент

> Существующий плеер для локальной библиотеки и прежнего API. Это не клиент платформы Vision Audio v2; новое развитие отложено по roadmap до Ф5. Встроенный Node/API-сервер из APK удалён.

## Безопасные границы

- Личная библиотека на телефоне может использоваться офлайн.
- Инструкций по подключению к домашнему или публичному legacy API здесь нет: старый API по умолчанию слушает `0.0.0.0`, работает через HTTP и имеет слабые credentials по умолчанию.
- Не подключайте приложение к legacy API в домашней сети или интернете с настройками по умолчанию; не открывайте его через firewall, роутер или туннель.
- Loopback-контур v2 на `127.0.0.1` предназначен для локальной проверки на том же Windows-ПК и не доступен телефону как сетевой сервер. См. [`../../docs/BETA-WINDOWS-LOCAL.md`](../../docs/BETA-WINDOWS-LOCAL.md).

## Разработка клиента

Требуются Node.js `>=22.5` и зависимости мобильного проекта:

```bash
cd apps/mobile
npm ci
npx tsc --noEmit
npx expo start
```

Клиентские и локальные тесты из корня репозитория: `npm run test:all`.

## Релизы

Android workflow по умолчанию собирает только временный artifact. Публикация в GitHub Releases требует явного решения владельца и release-opt-in. Процесс сборки, ограничения и release guards описаны в [`../../docs/ANDROID.md`](../../docs/ANDROID.md).
