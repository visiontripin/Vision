# Changelog

## 0.2.0 — 2026-11-10

Фаза 1 «Прод-готовность веба»: поиск, метаданные, безопасные медиа-ссылки,
наблюдаемость и «Продолжить слушать».

### Добавлено

- **FTS5-поиск** (`unicode61 remove_diacritics 2`) по названию, артисту, альбому,
  жанру и описанию с префиксным совпадением, сортировками
  (`relevance|recent|oldest|title|plays|duration`), `limit/offset` и `X-Total-Count`.
  Индекс синхронизируется триггерами и в транзакциях правки/удаления.
- **Миграции БД** с таблицей `schema_version`: `001-base`, `002-fulltext-search`,
  `003-checksum` (уникальный частичный индекс), `004-listens`. Идемпотентны,
  применяются при старте, статус виден в `/api/health`.
- **Теги и обложки из файлов** — собственный парсер без зависимостей: ID3v2.3/2.4
  (включая APIC), FLAC Vorbis comments + PICTURE, WAV `LIST/INFO` и `id3 `-чанк,
  Ogg/Opus, MP4 `ilst`, ID3v1 в хвосте. Лимит обложки 5 МБ, ошибки парсинга не
  ломают загрузку.
- **Подписанные медиа-URL**: `GET /api/media?ids=` выдаёт HMAC-SHA256 ссылки на
  поток и обложку с TTL (`MEDIA_URL_TTL_MS`). Токен больше не попадает в URL —
  `?token=` удалён.
- **Дедупликация по SHA-256** при загрузке: `409 duplicate` + существующий трек.
- **История прослушиваний** (`/listen`, `/api/history`) и блок «Продолжить слушать»
  в веб-клиенте: карточки с позицией, запуск с того же места.
- **Наблюдаемость**: `/metrics` в формате Prometheus (счётчики, гистограмма
  задержек, gauge по библиотеке), структурные JSON-логи с `X-Request-Id`,
  security-заголовки и CSP.
- **Надёжность SQLite**: WAL, `synchronous=NORMAL`, `foreign_keys=ON`,
  `busy_timeout=5000`.
- Веб-клиент: поиск через сервер (FTS) с дебаунсом и общим числом результатов,
  размер медиатеки в статистике, мобильный прогресс-бар с перетаскиванием и
  safe-area отступы, кэш подписанных ссылок с фоновым обновлением.

### Изменено

- Контракт API: `GET /api/tracks` принимает `offset` и `sort=relevance`,
  `GET /api/stats` отдаёт `bytes` и `migrations`.
- `packages/shared`: `media()`, `tracksPage()`, `listen()`, `history()`;
  `streamUrl()`/`coverUrl()` удалены — вместо них подписанные ссылки.
- Тестов API стало 14: подписи, Range/416, дедуп, FTS, история, плейлисты,
  метрики и заголовки безопасности.

### Ограничения версии

- Транскодирования всё ещё нет (Фаза 2): отдаётся оригинальный файл.
- `/api/v1` и OpenAPI-схема не сделаны — контракт описан в `docs/API.md`.
- Мобильное и десктопное приложения не пересобирались (нет устройства/Rust в CI).

## 0.1.0 — 2026-11-09

Первый рабочий срез: документация + фундамент продукта.

### Добавлено

- `docs/ROLES.md` — 11 ролей, зоны ответственности, RACI, протокол передачи работы,
  гейты качества и готовые системные промпты для агентов.
- `docs/PRODUCT.md` — scope MVP, non-goals, сценарии, критерии приёмки, NFR.
- `docs/ARCHITECTURE.md`, `docs/API.md`, `docs/ROADMAP.md`, `docs/RUNBOOK.md`, ADR 0001–0005.
- API на Node 22 (`node:http`, `node:sqlite`) без внешних зависимостей:
  вход по паролю (HMAC-токен), загрузка с проверкой magic bytes, стриминг с Range/206,
  обложки с ETag, плейлисты, лайки, статистика, rate limit.
- Web-клиент (React 19 + TS + Vite): библиотека с поиском/фильтрами, drag&drop загрузка
  с расчётом волны в браузере, плеер (очередь, shuffle, повтор, Media Session,
  восстановление сессии), плейлисты, лайки, статистика, адаптивная тёмная тема.
- `packages/shared` — типы, HTTP-клиент, утилиты (используются web и мобильным клиентом).
- Каркасы: Expo-приложение (вход, библиотека, плеер) и Tauri 2 (глобальные медиа-клавиши,
  CSP, автообновление).
- 9 контрактных тестов API (`npm test`), скрипт демо-наполнения, скрипт бэкапа, Dockerfile, CI.

### Известные ограничения

- Нет транскодирования (нужен ffmpeg): отдаётся оригинальный файл; FLAC не играет в Safari.
- Мобильная и десктопная сборки не проверялись в этом окружении (нет Rust и устройств).
- Обложки: API готов (`PUT /api/tracks/:id/cover`), UI-загрузки пока нет — рисуются заглушки.
- Нет публичных ссылок и шаринга (этап 4).
