# Разработка Vision Audio

> Внутренняя техническая памятка. Это не инструкция по установке продукта: Vision Audio v2 пока не выпущен и не открыт для пользователей.

## Требования

- Node.js `>=22.5` и npm.
- Для локальной проверки v2 на выбранной целевой среде — Windows 10/11, Docker Desktop с WSL2 и PostgreSQL/pgvector через отдельный loopback-only Compose-контур. Порядок действий и ограничения описаны в [`BETA-WINDOWS-LOCAL.md`](BETA-WINDOWS-LOCAL.md).

## Установка и проверки

Из корня репозитория:

```bash
npm ci
npm run test:all
npm run typecheck:api
npm run check:api-types
npm run build
npm run build:console
```

`npm run test:all` проверяет API, клиентский код и вспомогательные скрипты. `npm run build` собирает текущий web-плеер, но не подключённый к v2 интерфейс; `npm run build:console` собирает панель и не проверяет Windows-службу/установщик. Сборки создают локальные артефакты в `dist/`; они не являются релизом и не должны добавляться в Git.

Обновление клиентских типов из OpenAPI выполняется командой `npm run generate:api-types`; после неё проверьте `npm run check:api-types` и тесты.

## Локальные контуры

- **Платформенный v2 API:** используйте только сценарий из [`BETA-WINDOWS-LOCAL.md`](BETA-WINDOWS-LOCAL.md). Он привязывает API к `127.0.0.1`, не публикует порт PostgreSQL и не включает регистрацию.
- **Текущий legacy API:** не используйте `npm start` на домашней сети или в интернете. Он по умолчанию слушает `0.0.0.0` и сохраняет legacy-учётные данные по умолчанию. Не открывайте порт в firewall, не настраивайте port forwarding и сначала прочитайте [`RUNBOOK.md`](RUNBOOK.md).

Автоматические тесты и Linux-сборки не подтверждают запуск Docker, настоящей PostgreSQL, Windows-службы или установщика. Эти проверки остаются отдельными и не означают готовность беты.

## Секреты и артефакты

- Не добавляйте `.env`, `.env.platform.local`, токены, пароли, тестовые данные участников или пользовательские аудиофайлы в Git.
- `node_modules/`, `dist/` и временные артефакты сборки локальны и исключены из версионирования.
- Не загружайте в публичное Pages-демо приватные или чужие материалы.
