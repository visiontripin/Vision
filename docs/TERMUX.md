# Termux — архивная заметка о legacy API

> **Инструкцию установки/запуска Termux-сервера отозвали из активного набора.** Она относилась к одно-владельческому legacy API и не является способом тестирования Vision Audio v2.

Legacy API по умолчанию слушает `0.0.0.0`; запуск с сетевым bind без явно заданного `VISION_PASSWORD` или `VISION_PASSWORD_FILE` теперь блокируется. Скрипт `scripts/termux-setup.sh` создаёт случайный пароль и хранит его в приватном файле данных, но legacy API всё равно использует незашифрованный HTTP и не предназначен для публичного доступа. Не открывайте порт через firewall, роутер, VPN/tunnel или port forwarding. Эта запись намеренно не содержит команд установки и удалённого доступа.

Мобильный Vision Audio остаётся клиентом; сервер Node/JNI внутри APK удалён. Целевая локальная проверка v2 выполняется на Windows 10/11 через Docker Desktop/WSL2, с API только на `127.0.0.1:4400`. См. [`BETA-WINDOWS-LOCAL.md`](BETA-WINDOWS-LOCAL.md); этот контур не доступен телефону и не является публичным staging.

Схема прежнего распределённого режима остаётся в [`DISTRIBUTED.md`](DISTRIBUTED.md) и [`SYNC.md`](SYNC.md) исключительно как техническая история; она не разрешает публикацию или репликацию пользовательской музыки.
