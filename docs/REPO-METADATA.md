## Лицензия

В репозитории нет `LICENSE`. Пока владелец не выбрал лицензию, проект нельзя считать open source по умолчанию; нельзя добавлять MIT (или другую) лицензию автоматически. Нужно отдельно решить, распространяется ли лицензия на код, дизайн, документацию, изображения/аудио и зависимости.
