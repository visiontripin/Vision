# Закрытая бета — вопросы для формы обратной связи

**Черновик:** не использовать для сбора данных до выбора приватного канала и legal/privacy review. Не включать файл в публичную форму без согласования.

## Контекст участника

- Роль: артист / слушатель / предпочитаю не отвечать.
- Сессия/дата теста: необязательное поле, без публичного токена или ID.
- Можно ли связаться для уточнения? да / нет (отдельный opt-in).

## Вопросы

1. Что вы хотели сделать и получилось ли это?
2. Насколько быстро началась музыка? Что было непонятно?
3. Какой момент заставил продолжить или остановиться?
4. Для слушателя: почему, по вашему мнению, система предложила этот трек? Было ли объяснение понятным?
5. Для артиста: насколько понятны шаги проверки прав, статус публикации и статистика?
6. Какие реплики помогли, а какие мешали? Какие форматы вы бы отключили?
7. Сколько времени вы слушали волну? (диапазон, не точная история)
8. Был ли skip/ошибка/загрузка/жалоба? Опишите без паролей, токенов, платёжных данных или чужих файлов.
9. Есть ли проблема доступности, приватности или безопасности? Для срочных/правовых вопросов используйте отдельный приватный канал, который будет указан после его утверждения.
10. Можно ли связаться для уточнения? Отдельное разрешение для публичной цитаты — только в отдельной форме.

## Предупреждения перед отправкой

- Не прикладывайте аудиофайлы, документы о правах, адреса, пароли или токены.
- Не отправляйте чужие персональные данные.
- Отправка отзыва не означает согласия на публикацию.
- Ссылка на утверждённую privacy notice и срок хранения должны появиться до запуска формы.
