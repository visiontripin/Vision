# Roadmap (v1, история)

> Актуальная версия плана — `docs/IMPROVEMENTS.md` (улучшения, оптимизации и дорожная карта v2,
> построенная на разборе SoundCloud). Этот файл оставлен как история этапов 0–4.


Оценки — для команды из 2–3 человек (или одного агента с ролями из ROLES.md).
Каждый этап заканчивается гейтом качества (см. ROLES.md §5).

## Этап 0 — Фундамент (завершён в этом коммите)
- [x] Роли, RACI, протокол передачи работы, промпты агентов (`docs/ROLES.md`).
- [x] Продуктовое описание, scope, non-goals, критерии приёмки (`docs/PRODUCT.md`).
- [x] Архитектура, модель данных, ADR (`docs/ARCHITECTURE.md`), контракт API (`docs/API.md`).
- [x] Монорепо, общий пакет типов, API с SQLite, стриминг с Range.
- [x] Web MVP: вход, библиотека, поиск, загрузка (drag&drop + peaks), плеер, плейлисты, лайки.

## Этап 1 — Веб-версия до продакшена (1–2 недели)
- [ ] Публикация: Docker, TLS, бэкапы, health-мониторинг (`OPS`).
- [ ] Тест-план + e2e Playwright, контрактные тесты API (`QA`).
- [ ] Виртуализация списка, URL-состояние фильтров, bulk-загрузка с очередью.
- [ ] Теги из файла (ID3 через `music-metadata` на клиенте или сервере).
- [ ] Горячие клавиши, медиа-уведомления браузера (Media Session API).
- [x] Приватные ссылки на трек/плейлист с сроком жизни — v0.12.0 (`docs/adr/0007-private-links.md`).
- [x] Полноэкранный плеер с волной-скраббером (веб и мобильное приложение) — v0.13.0.
- [x] Таймкод-комментарии для приглашённых (только по ссылке) — v0.14.0.
- [x] Панель запуска и админки отдельным приложением для Windows и Android — v0.15.0
  (`apps/console`, сервер отдаёт её по `/admin`).
- [x] oEmbed и встраиваемый виджет `/embed/:token` — v0.16.0 (`docs/API.md`).
- [x] Журнал действий и аудит доступа (G10) — v0.17.0 (вкладка «Журнал» в панели).
- [x] Вход по ссылке, Web Share, PWA share target (F1, F5) — v0.18.0.

## Этап 2 — Мобильные приложения (3–4 недели, `MOB`)
- [ ] Expo-проект в `apps/mobile`, вход по токену, библиотека, плеер.
- [ ] Фоновое воспроизведение (`react-native-track-player`), медиа-уведомления, Bluetooth.
- [ ] Офлайн-кэш прослушанного, докачка, управление диском.
- [ ] Загрузка файлов из «Файлов»/«Музыки» на телефоне.
- [ ] Android: подпись AAB, внутреннее тестирование; iOS: TestFlight, background audio capability.

## Этап 3 — Десктоп (2–3 недели, `DSK`)
- [x] Tauri 2 в `apps/desktop`, сборка из `apps/web/dist` — v0.11.0, `docs/DESKTOP.md`.
- [x] Трей, глобальные медиа-клавиши, drag&drop файлов, «свернуть в трей» — v0.11.0;

## Этап 4 — Углубление (по запросу, `PO` решает)
- [ ] Транскодирование в opus/aac + HLS-адаптив, серверный ffmpeg-воркер.
- [ ] Диаграмма громкости (loudness), gapless-плейлисты, кроссфейд.
- [ ] Комментарии на таймкоде только для себя, заметки.
- [ ] Импорт из SoundCloud/локальных папок, дедупликация по хешу.
- [ ] Синхронизация между устройствами (позиция, очередь), офлайн-режим.

## Риски и ответы
| Риск | Ответ |
|------|-------|
| Нет ffmpeg на сервере → нет транскодинга | На MVP отдаём оригинальный файл; браузеры играют mp3/aac/ogg/flac (кроме Safari+flac) |
| Ограничение хостинга по диску | Лимит загрузки + мониторинг `diskFreeMb`, вынос медиа в S3 |
| iOS-фон без нативной сборки | Expo dev build, `UIBackgroundModes: audio`, тест на устройстве |
| Потеря файлов | Атомарная запись, ежедневный бэкап, проверка восстановления |
