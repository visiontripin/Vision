# Vision Audio — продуктовое описание

## 1. Цель

Личная аудиоплатформа: загрузить свою музыку/записи, собрать библиотеку,
слушать с любого устройства без чужих рекомендаций, рекламы и модерации.
Референс UX — веб-версия SoundCloud; отличие — один владелец, приватность по умолчанию.

Метрика успеха MVP: **от открытия приложения до первого звука — ≤ 2 клика**,
**загрузка трека — ≤ 30 секунд**, **поиск по 5 000 треков — < 100 мс**.

## 2. Персоны

| Персона | Контекст | Что важно |
|---------|----------|-----------|
| Владелец (основная) | Музыкант/меломан, свои записи и архивы | Быстрая загрузка, теги, плейлисты, доступ с телефона |
| Слушатель (гость) | Друг по приватной ссылке | Открыть ссылку и слушать без установки |

## 3. Границы MVP (этап 1–2)

**Входит**
- Вход по паролю владельца, токен-сессия.
- Загрузка аудио (mp3, wav, ogg, flac, m4a) с метаданными: название, исполнитель, альбом, жанр, описание, обложка.
- Библиотека: список, поиск по названию/исполнителю/жанру, сортировка, фильтр «лайкнутые».
- Плеер: play/pause, seek по волне, громкость, shuffle, repeat, очередь, горячие клавиши.
- Плейлисты: создание, добавление/удаление, порядок.
- Лайки, счётчик прослушиваний, статистика библиотеки.
- Адаптивная вёрстка (desktop → 360px).

**Не входит (non-goals MVP)**
- Соцсеть: подписки, комментарии на таймкоде, репосты, рекомендации.
- Публичный каталог и поиск по чужим трекам.
- Монетизация, права, модерация.
- Транскодирование в HLS и адаптивный битрейт (этап 3+).
- Живые трансляции, чат, редактор аудио.

## 4. Пользовательские сценарии

1. **Первый запуск**: открыть → ввести пароль → пустая библиотека с явным CTA «Загрузить трек».
2. **Загрузка**: перетащить 5 файлов → метаданные подставляются из имени файла → проставить жанр → «Загрузить» → прогресс по каждому файлу.
3. **Прослушивание**: клик по строке → трек играет, нижняя панель показывает волну → клик по волне = seek.
4. **Плейлист**: «＋» у трека → «Новый плейлист» → имя → трек внутри, drag&drop порядка (этап 2).
5. **Поиск**: набрать «live» → мгновенная фильтрация, подсветка совпадений.
6. **Возврат**: перезагрузка страницы → плеер восстанавливает последний трек и позицию.

## 5. Критерии приёмки (примеры)

- **AC-1**: при загрузке файла без тегов название = имя файла без расширения, исполнитель = «Unknown».
- **AC-2**: файл не-аудио с расширением `.mp3` отклоняется с понятной ошибкой, библиотека не меняется.
- **AC-3**: seek на 80% трека при стриминге выдаёт HTTP 206 и звук без повторной загрузки с начала.
- **AC-4**: нажатие Space ставит на паузу, если фокус не в поле ввода.
- **AC-5**: удаление трека убирает его из всех плейлистов и из текущей очереди.
- **AC-6**: при 401 клиент показывает экран входа, не теряя введённые метаданные загрузки.

## 6. Ключевые экраны

`Login` · `Библиотека (Home)` · `Плейлисты / плейлист` · `Лайкнутое` · `Статистика` ·
`Модалка загрузки` · `Постоянный плеер` · `Очередь`.

## 7. Нефункциональные требования

- Доступность: AA-контраст, полное управление с клавиатуры, ARIA для плеера и списков.
- Производительность: первый экран < 1 с на локали, 60 fps при скролле 5 000 строк (виртуализация — этап 2).
- Приватность: всё приватно по умолчанию; публичная ссылка — только по явному действию (этап 4).
- Данные: ежедневный бэкап БД + медиа, восстановление проверяется раз в месяц.
- Совместимость: Chrome/Edge/Safari/Firefox (2 последние версии), Android 9+, iOS 15+,
  Windows 10+, Ubuntu 22.04+.
