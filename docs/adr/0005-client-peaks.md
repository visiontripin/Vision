# ADR 0005 — Пики волны считает клиент

**Контекст.** Для waveform нужен анализ амплитуды. ffmpeg на сервере — лишняя зависимость,
время обработки и очередь задач.

**Решение.** Браузер декодирует файл через Web Audio API и отправляет 180 нормализованных
RMS-значений при загрузке в `?peaks=`. Сервер валидирует (массив ≤ 400 чисел 0..1) и хранит
JSON в `tracks.peaks`. Если peaks нет (Safari не смог декодировать FLAC) — клиент рисует
детерминированную псевдо-волну.

**Последствия.** Waveform виден сразу после загрузки, сервер остаётся без медиа-зависимостей.
Минус: пики не пересчитать без исходного файла (пересчёт возможен только на клиенте) и они
не отражают громкость после возможного транскодирования — для навигации этого достаточно.
