# ADR 0006 — Локальный режим (IndexedDB) для статического хостинга

**Контекст.** Нужно, чтобы веб-версию можно было открыть «из GitHub» без запуска
Node-сервера: GitHub Pages отдаёт только статику, а API требует процесс и диск.

**Варианты.** Развернуть сервер на VPS (не «из GitHub», нужен хостинг) ·
GitHub Codespaces (тяжело, нужен аккаунт и запуск) · сделать клиент полностью
автономным (IndexedDB) и публиковать статику.

**Решение.** Клиент работает в двух режимах. `VITE_LOCAL_MODE=1` подменяет HTTP-клиент
на `LocalClient` с тем же интерфейсом: треки и плейлисты в IndexedDB, аудио — Blob,
воспроизведение через `URL.createObjectURL`. Режим self-hosted остаётся по умолчанию
для `npm start`.

**Последствия.** Сайт живёт на GitHub Pages без сервера и без затрат; данные приватны
(остаются в браузере), но не синхронизируются между устройствами и теряются при очистке
данных сайта. Лимит — квота IndexedDB (обычно гигабайты). Для библиотеки на несколько
устройств используется self-hosted режим; синхронизация — этап 4.
