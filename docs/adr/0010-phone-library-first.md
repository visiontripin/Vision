# 0010. Телефон — самостоятельный плеер, сервер необязателен

**Дата:** 2026-11-12
**Статус:** принято (0.27.0, mobile 0.7.0)
**Роли:** PO, MOB, UX, TL

## Контекст

Мобильное приложение было тонким клиентом домашнего сервера: первый экран просил
адрес и пароль, а без запущенного Node-процесса показывал `Network request failed`.
Владелец сформулировал ожидание прямо: «приложение должно само поднимать сервер
автоматически, а я только должен выбирать музыку». Для плеера это верно —
человек включает музыку, а не администрирует сервер.

## Варианты

1. **Встроить Node-сервер в APK** (`nodejs-mobile`): телефон становится сервером и
   раздаёт музыку другим устройствам. Самый буквальный ответ на запрос, но это
   отдельный большой этап: нужен билд Node 22+ (серверу нужен `node:sqlite`), а
   в npm лежит `nodejs-mobile-react-native` с Node 18 — то есть форк
   (`RockinChaos/nodejs-mobile` v22.23.4) и свой JNI-модуль.
2. **Автопоиск сервера в Wi-Fi**: адрес вводить не надо, но сервер всё равно
   обязателен, а с выключенным ПК музыки нет.
3. **Библиотека на телефоне** (выбрано на этом шаге): файлы устройства — первый
   источник, сервер — необязательный второй.

## Решение

Приложение работает как самостоятельный плеер:

- библиотека (файлы, метаданные, плейлисты, статистика) хранится на устройстве
  (`src/local.tsx`, ядро — `src/lib/local.ts`);
- импорт — файлы с телефона и добавление по ссылке;
- подключение к домашнему серверу — отдельный необязательный экран, ошибка
  соединения ничего не блокирует;
- источник звука в плеере: локальный файл → офлайн-копия → поток с сервера.

## Последствия

- Приложение полезно сразу после установки, без сервера, сети и пароля.
- Библиотека не синхронизируется между устройствами сама: для этого нужен сервер
  (он остаётся источником для тех, у кого он есть).
- Встроенный Node ещё не сделан. Требования к нему зафиксированы: Node 22+
  (`node:sqlite`), `RockinChaos/nodejs-mobile` как основа, JNI-модуль, запуск
  сервера в foreground-сервисе, порт 4000 на loopback. Это следующий этап, а не
  замена текущего решения.
