# 0019. Progressive-секвенсор на MVP, HLS/MSE и live-mix позже

**Дата:** 2026-11-12
**Статус:** принято для MVP радио; транспортные гейты уточняются в Ф3
**Роли:** TL, FE, RADIO

## Контекст

Длинные радио-сессии требуют надёжной предзагрузки, но серверный live-mix дорог и усложняет персонализацию и восстановление сессии.

## Решение

На MVP использовать progressive-секвенсор сегментов, который планирует следующий контент и загружает его заранее. HLS/MSE (включая hls.js) остаётся отдельной задачей Ф3.13 для длинных сессий/слабых сетей; общий live-mix не входит до отдельного решения после Ф5.

## Последствия

- Веб-клиент должен иметь честное состояние offline/пропуска сегмента и восстанавливаемую очередь.
- Существующий API HLS для отдельных треков не означает, что радио уже использует HLS.
- Решение о реализации HLS/MSE принимается по метрикам беты, а не по инерции технического бэклога.
