# ADR 0003 — Сырое тело запроса вместо multipart для загрузки

**Контекст.** Нужна потоковая запись файлов до 500 МБ без зависимостей.

**Решение.** `POST /api/tracks?...метаданные` с телом = байты файла. Метаданные в query,
волна — JSON-строкой (до 8 КБ). Запись идёт потоком во временный файл, затем атомарный
`rename`. Формат определяется по magic bytes из первых байт.

**Последствия.** Нет парсера multipart и его уязвимостей; прогресс на клиенте — через
`xhr.upload.onprogress`. Ограничение: одна загрузка = один запрос, нет пакетной отправки
(на клиенте это последовательный цикл). Имя файла с диска не используется вообще.
