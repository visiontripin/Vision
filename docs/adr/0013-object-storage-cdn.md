# 0013. S3-совместимое хранилище и CDN для опубликованного медиа

**Дата:** 2026-11-12
**Статус:** принято как целевая архитектура; provider и бюджет не выбраны
**Роли:** TL, OPS, BE

## Контекст

Локальный диск подходит для разработки и личного self-hosted режима, но не для масштабируемой публичной медиатеки с подписанными URL, lifecycle и доставкой аудио.

## Решение

Для публичного контура использовать S3-совместимое объектное хранилище и CDN; локальный файловый backend оставить для разработки и совместимого личного режима. Не выбирать конкретного провайдера до ответа на вопросы юрисдикции, бюджета и географии пользователей.

## Последствия

- API выдаёт ограниченные по времени подписанные URL; права доступа и lifecycle задаются на объектном слое.
- Метаданные/БД остаются отдельным источником правды; удаление и takedown должны инвалидировать URL и CDN-кэш.
- Реализация блокируется операционным бюджетом, регионом хранения и планом миграции из SQLite/local storage.
